# Texture credits

The worn brake disc look (`mod/art/slrr_partwear/disc_rust_*`, made by `tools/make_disc_rust_textures.py`) is derived from a CC0 photograph set of rust. The photographs are not shipped: the script reads the colour, normal and roughness maps from a folder outside the mod and writes three 512 px detail textures (a rust colour layered with a seeded patch mask, the photograph's pitting as a normal detail, and a roughness detail).
